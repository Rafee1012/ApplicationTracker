# ApplicationTracker
For Tracking
---

Run domain commands with ```cd src/ApplicationTracker```.
- Build project with: ```dotnet build```.
- Run project with: ```dotnet run```.
- Check packages with: ```dotnet list package```.

Run API commands with ```cd src/ApplicationTracker.Api```.
- Build project with: ```dotnet build```.
- Run project with: ```dotnet run```.

Run tests commands with ```cd tests/ApplicationTracker.tests```.
- Run tests with: ```dotnet test```.
- Build project with: ```dotnet build```.
- Run project with: ```dotnet run```.
